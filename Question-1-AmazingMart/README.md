AmazingMart EU Sales Analysis Capstone Project
Report

Prepared by: Daniel Moses
1. Project Overview
This capstone project analyzed the AmazingMartEU2Geo.xlsx dataset using Microsoft Excel and
Power BI. The objective was to clean, model, analyze, and visualize the data to answer key
business questions and present the findings in a professional dashboard.

2. Business Problem
The client requested analysis of quantity distribution, regional sales and profit trends over time,
product sub-category performance, profit by country and category, and the ship mode contributing
the highest profit.

3. Dataset
Dataset: AmazingMartEU2Geo.xlsx from the Brainpals Academy Dataset Repository. The
workbook contained two related sheets requiring data modeling.

4. Tools Used
Microsoft Excel, Power BI, Power Query, DAX, GitHub, AI assistance for documentation and
planning.

5. Methodology
• Imported both tables. • Performed data cleaning (missing values, duplicates, data types). •
Created relationships between tables. • Built measures and calculated fields. • Designed KPI cards
and interactive visuals. • Created a professional dashboard and documented the project on GitHub.

6. Dashboard Components
KPI Cards (Sales, Profit, Quantity, Average Sales), Histogram, Regional Trend Line Chart, Matrix
for Sub-category Analysis, Country Profit Summary, Ship Mode Contribution Chart, and interactive
slicers.

7. Key Findings
The dashboard highlights quantity ordering patterns, compares regional performance, identifies
low-performing sub-categories for review, summarizes profitability by country and category, and
identifies the most profitable shipping mode.

8. Deliverables
Excel analysis, Power BI dashboard, screenshots of the workflow, dataset, GitHub repository, and
project documentation.

9. Conclusion
This project demonstrates end-to-end data analytics skills including data preparation, modeling,
visualization, dashboard development, business insight generation, and professional
documentation.
