# 📊 Data Analytics Capstone Projects

## Overview

This repository contains two end-to-end data analytics projects completed as part of my Data Analytics capstone.

The projects demonstrate practical experience in **data cleaning, data analysis, data modeling, SQL, Microsoft Excel, Power BI, DAX, dashboard development, and business intelligence**.

---

## 📁 Project 1 — AmazingMart EU Sales Analysis

**Objective:** Analyze AmazingMart's sales data to understand sales and profit performance across regions, countries, product categories, sub-categories, and shipping modes.

### Key Analysis
- Quantity distribution using a histogram
- Sales and profit performance by region over time
- Sub-category profitability analysis
- Profit by country and product category
- Profit contribution by shipping mode
- Interactive Power BI dashboard

**Tools:** Microsoft Excel, Power BI, DAX

👉 [View Project 1](./Question-1-AmazingMart)

---

## 📁 Project 2 — TechNova Sales & Employee Performance Analysis

**Objective:** Analyze sales and employee performance using data from Excel and MySQL and develop an interactive Power BI reporting solution.

### Key Analysis
- Total sales by region
- Highest-selling product
- Profit calculation using a 20% margin
- Employee performance against sales targets
- Employees exceeding targets by more than 10%
- Bonus eligibility analysis
- Monthly sales trends
- Regional employee drill-through analysis

**Tools:** Microsoft Excel, MySQL, Power BI, DAX

👉 [View Project 2](./Question-2-TechNova)
