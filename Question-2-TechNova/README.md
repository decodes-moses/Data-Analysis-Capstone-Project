
# TechNova Sales & Employee Performance Analysis

## 📊 Project Overview

An end-to-end data analytics project analyzing sales and employee performance using Microsoft Excel, MySQL, and Power BI.

## 🎯 Business Problem

TechNova Retail needed to understand regional sales performance, product performance, employee target attainment, bonus eligibility, and sales trends using data stored across Excel and MySQL.

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- Power BI
- DAX
- Power Query

## 🔍 Key Analysis

- Sales by Region
- Highest-Selling Product
- Profit Analysis
- Employee Performance vs Target
- Employees Exceeding Target by More Than 10%
- Bonus Eligibility
- Monthly Sales Trends
- Regional Employee Drill-Through
